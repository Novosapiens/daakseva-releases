# Daakseva releases

Signed and notarized builds of Daakseva, a menu-bar email client for macOS built on [Mailspring](https://github.com/Foundry376/Mailspring). Apple Silicon (M1 or later) and macOS 13 Ventura or later.

**Install:** with Homebrew, see [novosapiens/homebrew-daakseva](https://github.com/Novosapiens/homebrew-daakseva). Or download the DMG from the [latest release](https://github.com/yashsaxena/daakseva-releases/releases/latest) and drag Daakseva to Applications. The app updates itself from here.
